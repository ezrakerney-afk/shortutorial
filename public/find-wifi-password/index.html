How to Find Your Wi-Fi Password

Forgot the Wi-Fi password and need to connect something new? Any device that's already connected can show it. Here's how on every common device.

Quick guide~2 minEasy
Show steps for
Easiest option · 30 seconds

Check the router first

Most home routers have the original Wi-Fi name and password printed on a sticker on the back or bottom, labelled Wi-Fi key, WPA key, Network key or Password. If nobody has changed it, that's your password.

Changed it and forgot? A device that's already connected can show it. Pick yours below.

FINDFind it on a device that's already connected

Use whichever device is already on the Wi-Fi.

  1. Go to Settings › Network & internet › Wi-Fi.
  2. Click your network's name (or Manage known networks, then the network) to open its properties.
  3. Click View next to View Wi-Fi security key.

Older versions of Windows don't have this button. Use the next step instead.

This works for any network the computer has ever connected to. Right-click Start, choose Terminal, and run the first command to list saved networks:

netsh wlan show profiles

Then run this, replacing NetworkName with the exact name from the list (keep the quotes):

netsh wlan show profile name="NetworkName" key=clear

The password is next to Key Content.

  1. Open the Passwords app (macOS Sequoia or later) and click Wi-Fi in the sidebar.
  2. Select your network, then hover over the hidden password to show it.

On older macOS, open Keychain Access, search for the network name, double-click it and tick Show password. You'll be asked for your Mac password.

  • iPhone (iOS 16 or later): go to Settings › Wi-Fi, tap ⓘ next to the network, then tap Password and unlock with Face ID or your passcode.
  • Android: go to Settings › Network & internet › Internet, tap the gear next to the network, then Share. A QR code appears, and on most phones the password is written underneath.

Sharing with a nearby iPhone or Mac is even easier: bring it close while it tries to join, and tap Share Password when asked.

If no device remembers it, the router itself always knows.

  1. On a connected device (a cable works too), open a browser and go to the router's address. It's on the sticker, often 192.168.1.1 or 192.168.0.1. Many internet providers also have an app.
  2. Sign in with the admin password on the sticker (this is different from the Wi-Fi password).
  3. Look under Wireless or Wi-Fi settings for the password, and change it if you like.
Last resort: holding the router's reset button for 10–30 seconds restores the password on the sticker, but also wipes all other settings. Some providers' routers need reconfiguring afterwards.
🔑
Password found.

Save it in a password manager or your phone's notes so you don't have to hunt for it again.

Still can't find it?

Call your internet provider. They can tell you the password or reset it remotely after checking your identity.

FAQCommon questions

Is the Wi-Fi password the same as the router password?

No. The Wi-Fi password connects devices to the network. The router (admin) password logs in to the router's settings. Both are often printed on the sticker.

Can I see the password for Wi-Fi I'm not connected to?

Only for networks your device has joined before. Otherwise you need to ask the owner.

Should I change the password on the sticker?

It's a good idea, especially if the sticker is visible to visitors. Choose something long that you can share easily, and update it on all your devices.

Why does my phone show a QR code instead of the password?

Other phones can scan the code to join without typing. Most Android phones also show the password text under the code.
