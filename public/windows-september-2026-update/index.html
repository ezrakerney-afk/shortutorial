Windows 11 September 2026 Update Problems

Windows 11's September updates broke sound, some apps and games, and more. Here's what's affected, what Microsoft has fixed so far, and what you can do right now.

ISSUESKnown problems and fixes

No sound from USB audio devices

Partly fixed
Caused by
KB5124008 (September 8)
Symptoms
No sound; volume stuck at zero; Sound settings unresponsive; Device Manager shows “This device cannot start (Code 10)”.
Affects
USB speakers, headsets and audio interfaces (USB Audio Class 1.0).
Status
The emergency update KB5129195 (September 14) fixed only surround-sound and 3D audio. Microsoft is still working on the rest.

What to do

  1. Install every update in Settings › Windows Update. Microsoft may include the full fix in the October 13 update.
  2. Switch the device to stereo. Some people got sound back this way. Go to Settings › System › Sound › More sound settings, select your USB device on the Playback tab, click Configure, choose Stereo and finish. Or open Properties › Advanced and pick a 2 channel format.
  3. Use your computer's built-in speakers, the headphone socket or Bluetooth in the meantime.
  4. Still nothing, and you need it working now? Remove the latest update (see how below).

Games and apps crash when they play sound

No fix yet
Caused by
KB5124010 (September 22)
Symptoms
Some apps fail to open, close without warning, or crash when you play music, change the volume or open audio settings.
Affects
Mostly older games, media players and apps that use Windows' built-in Dolby Digital (AC-3) decoder. Windows 11 24H2, 25H2 and 26H2.
Status
Confirmed by Microsoft. A fix is promised in a future update; no date given.

What to do

  1. In the app's or game's audio settings, turn off surround, 5.1 or Dolby output and choose stereo.
  2. For videos, use a player with its own decoder, such as VLC, which isn't affected.
  3. If an important app is unusable, remove KB5124010 (how below) until the fix arrives.

AMD graphics freezes, black screens or missing displays

Unconfirmed
Linked to
September 2026 updates, according to user reports
Symptoms
Driver timeouts, black screens, displays disappearing and freezes, even outside games.
Affects
Reports mention Radeon RX 6000, 7000 and 9000 series cards.
Status
Not on Microsoft's official known-issues list, and no fix announced. The cause isn't confirmed.

What to do

  1. Install the latest driver from AMD's driver page. Some users found older drivers didn't help.
  2. Removing the September update fixed it for some people (how below).
  3. Report it through the Feedback Hub app; the more reports Microsoft gets, the faster it's investigated.

Work PCs can't sign in to the company domain

Fixed
Caused by
KB5124008 and KB5129195 on PCs using Credential Guard
Symptoms
Can't sign in with work credentials; “trust relationship” errors. Signing in with cached details still works.
Fixed in
KB5124010 (September 22) and later.

What to do

Install the latest updates. If you still can't sign in, contact your IT team; Microsoft has published a rollback and repair procedure for administrators.

Black screen after signing in

Workaround available
Caused by
KB5120998
Symptoms
You sign in but see only a black screen, or the desktop doesn't load. Mostly affects virtual and work desktops.

What to do

  1. Press Ctrl Shift Esc to open Task Manager.
  2. Click Run new task, type explorer.exe and press Enter. Your desktop should appear.

HOW TORemove a problem update

Go to Settings › Windows Update › Update history. Look under Quality Updates for the KB numbers mentioned above and the date they installed.

  1. In Settings › Windows Update › Update history, scroll down to Related settings and click Uninstall updates.
  2. Click Uninstall next to the most recent update and restart.

Monthly updates include everything from earlier ones, so removing the newest one also removes the fixes before it.

Security trade-off. These updates also fix security holes. Only remove one if the problem really gets in your way, and reinstall as soon as Microsoft releases a fix.

In Settings › Windows Update, choose a pause length next to Pause updates. One or two weeks is enough for Microsoft to release a fix; then resume and update.

FAQCommon questions

Should I stop installing Windows updates?

No. Updates fix security holes that attackers actively use. If an update breaks something you need, remove that one, pause for a week or two, then update again once a fix is out.

How do I know which Windows 11 version I have?

Go to Settings › System › About and look at Version under Windows specifications, for example 25H2.

When will Microsoft fix these?

Microsoft's regular updates come out on the second Tuesday of each month; the next is October 13, 2026. It hasn't promised dates for the remaining audio or app-crash fixes.

I removed the update but Windows reinstalled it. What now?

Pause updates right after removing it (step 3 above). Windows reinstalls missing security updates automatically when updates aren't paused.
