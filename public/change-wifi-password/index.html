How to Change Your Wi-Fi Password

Kick off freeloaders, replace a weak password, or just change the one printed on the sticker. Here's how on any router, and how to get your devices back online afterwards.

Quick fix~10 minEasy
Before you start · 1 minute

Know which kind of router you have

  • From your internet provider (Xfinity, Spectrum, AT&T, Verizon, Cox and so on): the provider's app is usually the easiest way.
  • Mesh systems (eero, Google Nest Wifi, TP-Link Deco, Orbi): use their app.
  • A standalone router you bought (TP-Link, Netgear, ASUS and others): use its app or its web settings page.

The brand is printed on the router. Use a device that's connected to the network while you do this.

HOWChange your Wi-Fi password

Pick the method that matches your router.

Menu names change from time to time; look for Wi-Fi, Network or Wireless settings.

  • eero: eero app › Settings › Network name & password.
  • Google Nest Wifi: Google Home app › Wi-Fi › Network settings › Wi-Fi name and password.
  • TP-Link Deco: Deco app › More › Wi-Fi.
  • Netgear (Nighthawk or Orbi): the matching app › Wi-Fi settings.
  1. Open a browser and type the router's address. It's on the sticker; common ones are 192.168.1.1, 192.168.0.1 or 10.0.0.1.
  2. Sign in with the admin username and password from the sticker (not the Wi-Fi password).
  3. Open Wireless, Wi-Fi or WLAN settings and find the password field, sometimes called Passphrase, Network key or Pre-shared key.
  4. Set security to WPA3, or WPA2/WPA3 if offered (WPA2 if that's the only option). Then save or apply.
If your router has separate 2.4 GHz and 5 GHz networks, change the password on both.
  • At least 12 characters. Three or four random words is easy to type and hard to guess: maple-river-otter-42.
  • Don't use your address, phone number, names or the old password with a number added.
  • While you're there, change the admin password too if it's still the default from the sticker.

Every device disconnects when the password changes. On each one, select the network and enter the new password.

  • Smart TVs, printers, speakers and cameras each need reconnecting through their own settings or app.
  • Tip: keep the network name the same. Some smart devices reconnect more easily if only the password changed.
🔐
New password set.

Write it down somewhere safe, or save it in a password manager.

Can't sign in to the router?

Call your internet provider for routers they supplied. For your own router, a factory reset (hold the reset button 10–30 seconds) restores the sticker passwords, but erases all settings.

FAQCommon questions

Why change my Wi-Fi password?

To kick off neighbours or old guests who have it, after a breakup or roommate moves out, if it's still the default on the sticker, or if it's weak.

Will changing it kick everyone off?

Yes, every device disconnects and needs the new password. Plan time to reconnect smart devices.

Is the Wi-Fi password the same as the router password?

No. The Wi-Fi password lets devices join the network. The admin password lets you change the router's settings.

How do I share the new password easily?

iPhones and Macs can share it when a nearby Apple device tries to join. Android phones can show a QR code under the network's settings. Many router apps can make a guest network too.

What's a guest network?

A separate Wi-Fi network for visitors, with its own password, that can't see your own devices. Most routers and provider apps offer one.
