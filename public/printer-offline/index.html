Fix a Printer That Says “Offline”

The printer is on, but your computer insists it's offline. These fixes go from quickest to most thorough and work for HP, Canon, Epson, Brother and most other brands.

Quick fix~5–15 minEasy
Show steps for
Start here · 30 seconds

Check the printer itself

  • Is it switched on and awake? Press a button on it; many printers fall into deep sleep.
  • Any blinking lights or messages about paper, ink or a jam? Clear those first; some printers report “offline” when they're really stuck.
  • For Wi-Fi printers: is the printer's Wi-Fi light solid? If it's blinking or off, it's not on your network.

FIXTry these in order

Open a step, try it, then tell us if it worked.

  1. Turn the printer off and unplug it from the wall.
  2. Wait 30 seconds, plug it back in and turn it on.
  3. Restart your computer while the printer starts up.

This clears the most common cause: the printer or computer lost track of each other after sleeping.

One stuck document can block everything behind it and make the printer look offline.

Go to Settings › Bluetooth & devices › Printers & scanners, choose your printer, then Open print queue. Click the ··· menu and choose Cancel all.

In the queue window, if you see a Printer menu, open it and make sure Use Printer Offline is not ticked.

Click the printer icon in the Dock (or open System Settings › Printers & Scanners, choose the printer, then Printer Queue). Delete every job with the × button.

If the queue says Paused, click Resume.

Wi-Fi printers often drop off after a router restart, a new router, or a Wi-Fi password change.

  • Use the printer's screen or buttons to print a Network Configuration or Wireless Test page. It shows which Wi-Fi network it's on and its IP address.
  • That network name must match your computer's, including not being on a guest network.
  • If it's wrong, reconnect the printer with its Wi-Fi setup menu or the maker's app.
  • USB printer? Try a different cable and plug straight into the computer, not a hub.

The Print Spooler is the Windows service that handles printing. When it gets stuck, every printer looks offline.

  1. Search for Services in the Start menu and open it.
  2. Scroll to Print Spooler, right-click it and choose Restart.

Prefer a command? Open Command Prompt as administrator and run:

net stop spooler
net start spooler

This clears every printer and its queue, so macOS can set them up fresh.

  1. Open System Settings › Printers & Scanners.
  2. Control-click (or right-click) in the list of printers and choose Reset printing system.
  3. Confirm, then add your printer again with Add Printer, Scanner or Fax.
This removes all printers from the Mac, not just the broken one. You'll add back the ones you use.
  1. In Settings › Bluetooth & devices › Printers & scanners, select the printer and choose Remove.
  2. Also remove any duplicates like “Printer (Copy 1)”. Duplicates are a classic cause of the offline problem.
  3. Click Add device next to “Add a printer or scanner” and pick your printer when it appears.

Then set it as your default: select it and choose Set as default. If that button is missing, first turn off Let Windows manage my default printer.

  1. In System Settings › Printers & Scanners, select the printer and click Remove Printer (or the – button).
  2. Click Add Printer, Scanner or Fax and choose it from the list.
  3. If it doesn't appear, click the IP tab and type the IP address from the printer's network page (step 3).

Windows has a built-in printer troubleshooter in the Get Help app. Search for Get Help in the Start menu, type “printer offline” and run the printer troubleshooter.

Printer makers also have free apps that diagnose connection problems and update drivers:

  • HP: the HP app (formerly HP Smart) has a Diagnose & Fix tool.
  • Epson, Canon, Brother: download the setup or utility software for your model from their support sites (links below).

If the printer works, then goes offline again days later, its network address is probably changing. Your computer keeps looking at the old one.

  • Best fix: in your router's app or settings page, find the printer in the connected devices list and choose Reserve IP (sometimes called “DHCP reservation” or “Always use this IP”).
  • Also helps on Windows: in the printer's Printer properties › Ports, a Standard TCP/IP Port using the printer's IP is more reliable than a “WSD” port. Removing and re-adding the printer by IP address (step 5) sets this up.
  • Turn off any “deep sleep” or “Wi-Fi power save” setting in the printer's menu if it has one.
A bit more technical. If the router settings look confusing, it's fine to skip this. Re-adding the printer (step 5) works as a quick fix whenever it happens.

Printing again.

If it goes offline again in a few days, jump to the last step to stop it for good.

Still offline?
  • Try printing from your phone. If that works, the problem is the computer's setup; repeat step 5 carefully and remove every copy of the printer first.
  • If nothing can print to it, contact the printer maker's support. The printer's network card or firmware may need attention.

FAQCommon questions

Why does my printer keep going offline?

Usually because its network address changes after the router restarts, so your computer looks in the wrong place. Other causes are deep sleep mode, weak Wi-Fi where the printer sits, and duplicate printer entries. The last fix covers how to stop it.

It prints from my phone but says offline on my computer. Why?

The printer and network are fine; your computer has an outdated or duplicate entry for it. Remove every copy of the printer and add it again (step 5).

How do I find my printer's IP address?

Print a Network Configuration page from the printer's menu, or look in its Wi-Fi or Network settings on its screen. You can also find it in your router's list of connected devices.

Do I need to install the manufacturer's software?

Usually not. Windows and macOS include drivers for most printers. The maker's app is useful for setup on a new network, troubleshooting, scanning and ink levels.

Will reinstalling the printer delete anything?

No. It only removes the printer's entry and any waiting print jobs. Your documents are safe; just print them again afterward.
