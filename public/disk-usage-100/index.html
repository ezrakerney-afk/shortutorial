Fix 100% Disk Usage in Windows 11

Task Manager shows your disk pinned at 100% and everything crawls. There's no single cause, so this guide helps you find yours, then works through the fixes that help most people.

Quick fix~10–20 minWindowsEasy to medium
Start here · 2 minutes

Find out what's using the disk

Press Ctrl Shift Esc to open Task Manager, then click the Disk column header to sort by it. The app at the top is your culprit. Write its name down; the steps below tell you what to do about the usual suspects.

For more detail, search for Resource Monitor in the Start menu and open the Disk tab. It lists the exact files being read and written.

Just started the computer or installed updates? Windows often runs at 100% disk for 10–20 minutes after starting up or updating while it catches up. If it settles down on its own, nothing is wrong.

FIXTry these in order

Open a step, try it, then check Task Manager again.

In Task Manager, open the Performance page and click Disk 0. The type is shown at the top right: HDD or SSD.

This matters more than anything else. Old spinning hard drives (HDD) are slow enough that normal Windows background work can max them out. If you have an HDD, the steps below help, but the real fix is step 8.

SysMain (formerly Superfetch) preloads apps into memory to make them start faster. On slower drives it can keep the disk busy constantly. Turning it off is safe.

  1. Search for Services in the Start menu and open it.
  2. Double-click SysMain.
  3. Set Startup type to Disabled, click Stop, then OK.

You can turn it back on the same way if apps feel slower to open afterwards.

Windows Search builds an index of your files so searches are instant. If the index is damaged, it can rebuild over and over and keep the disk busy.

  1. Go to Settings › Privacy & security › Searching Windows.
  2. Click Advanced indexing options, then Advanced, then Rebuild.

The rebuild can take an hour and will use the disk while it runs, so start it before you step away. If disk usage is still maxed out afterwards, set the Windows Search service to Manual in Services the same way as SysMain. Search still works, just more slowly.

  • Delivery Optimization shares Windows updates with other PCs. Turn it off in Settings › Windows Update › Advanced options › Delivery Optimization.
  • OneDrive, Google Drive, Dropbox: if one is near the top of the Disk column, it's syncing. Let it finish, or pause syncing from its icon near the clock.
  • Antivirus: a full scan reads every file. Let it finish, or schedule scans for when you're not using the computer. Never run two antivirus apps at once.

An outdated storage controller driver is a known cause of 100% disk usage on some laptops, especially ones using Intel Rapid Storage Technology.

  1. Install everything in Settings › Windows Update, including Advanced options › Optional updates, where driver updates appear.
  2. Then check your laptop maker's support site (Dell, HP, Lenovo, Acer and so on) for the latest chipset and storage or Rapid Storage drivers for your exact model.

A failing drive takes much longer to read data, so it sits at 100% while doing very little. Check it before you spend more time on software fixes.

Right-click the Start button, choose Terminal (or PowerShell), and run:

Get-PhysicalDisk | Select FriendlyName, MediaType, HealthStatus

Anything other than Healthy is a warning sign. For more detail, the free tool CrystalDiskInfo shows a plain Good / Caution / Bad rating.

Caution or Bad? Back up your files now, before trying anything else. A failing drive can stop working without further warning.

Right-click the Start button, choose Terminal (Admin), and run:

chkdsk C: /scan

This checks the drive while you keep working. If it reports problems, it will tell you to run a repair, which needs a restart.

If your computer has an HDD and everything above helped only a little, this is the permanent fix. Swapping a hard drive for a solid-state drive is the single biggest speed upgrade for an older computer, and 100% disk usage almost always disappears.

Most repair shops can copy everything to the new drive so you keep all your files and apps. The parts are inexpensive compared with a new computer.

📉
Disk usage back to normal.

If it creeps back, check Task Manager again; it's usually the same app each time.

Still stuck at 100%?
  • Test in Safe Mode: if disk usage is normal there, a program that starts with Windows is the cause. Disable startup apps in Task Manager one at a time to find it.
  • As a last resort, Settings › System › Recovery › Reset this PC with Keep my files reinstalls Windows while keeping your documents.

FAQCommon questions

Is 100% disk usage bad for my computer?

It won't damage anything by itself, but it makes everything painfully slow because programs have to wait for the drive. Constant 100% on a hard drive that's also making clicking noises can be a sign it's failing; check its health (step 6).

Is it safe to disable SysMain?

Yes. It's a speed-up feature, not something Windows needs to work. On computers with an SSD you may not notice any difference either way.

Why did it start right after upgrading to Windows 11?

Upgrades trigger a lot of one-time background work: re-indexing files, installing follow-up updates and optimising apps. Give it a day. If it's still happening, outdated storage drivers from the old version of Windows are a common cause (step 5).

Will turning off hibernation fix it?

It helps some people, but mostly because it frees up several gigabytes of space. Run powercfg /hibernate off in Terminal (Admin) if your drive is also nearly full. Note this turns off hibernation and Fast Startup.

Task Manager says 100% but nothing is listed using much. Why?

The work may be coming from Windows itself (listed as “System”) or from a failing drive that's slow to respond. Check the drive's health (step 6) and look at Resource Monitor's Disk tab for the files involved.
