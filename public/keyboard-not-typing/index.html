Keyboard Not Typing? Fix It

You press keys and nothing happens, or the wrong characters appear. It's usually a setting, a connection or crumbs, not a broken keyboard. Work through these fixes in order.

Quick fix~5–15 minEasy

Quick test · 30 seconds

Is it every key, or just some?

  • Nothing works at all: a connection, power or driver problem. Start at step 1.
  • Some keys type the wrong thing (like @ instead of "): the keyboard layout is wrong. Jump to step 5.
  • Number keys on the right don't work: press Num Lock.
  • Keys are slow or ignore quick presses: an accessibility setting is on. Step 4.

  • USB keyboard: unplug it, wait 10 seconds and plug it into a different USB port, directly on the computer rather than a hub.
  • Wireless with a USB receiver: replace or recharge the batteries, unplug the receiver for 10 seconds, and plug it back in.
  • Bluetooth: check it's charged and switched on, then remove it from Settings › Bluetooth & devicesSystem Settings › Bluetooth and pair it again.
  • MacBook keyboard not responding? Plug in the charger: a hidden low-battery warning can block typing.
  • Some laptops have a keyboard lock or Fn lock key; press Fn together with Esc or the key with a padlock icon.
  • Tablet-style laptops and Surface devices disable the keyboard when it's folded back; make sure it's fully attached and flat.
  • Gaming keyboards may have a “Windows key lock” or game mode switch.

Filter Keys makes Windows ignore brief or repeated key presses, and it's easy to switch on by accident by holding Shift for 8 seconds.

Go to Settings › Accessibility › Keyboard and turn off Filter keys and Sticky keys.

  • System Settings › Accessibility › Keyboard: turn off Slow Keys, which makes you hold keys longer before they register.
  • System Settings › Accessibility › Pointer Control: turn off Mouse Keys, which turns letter keys into mouse controls.

If keys type the wrong symbols, Windows may be using another language's layout. Press Win Space to switch between installed layouts, or go to Settings › Time & language › Language & region, open your language's options, and remove keyboards you don't use.

Typing again.

Clean your keyboard every month or two to keep crumbs from causing sticky keys.

Still not working?

If no keyboard works on this computer, the computer itself may need repair; contact the maker. If only a laptop's built-in keyboard has failed, an external USB keyboard is a cheap workaround.

FAQCommon questions

Why is my keyboard typing the wrong letters?

The keyboard layout is set to another language, such as UK instead of US. See step 5. On Windows, Win Space or Alt Shift can switch layouts by accident.

Why do only some keys not work?

Usually dirt or crumbs under those keys, or liquid damage. Clean the keyboard (step 7). If it's the number pad, press Num Lock.

My laptop keyboard stopped working after an update.

Restart, then update or reinstall the keyboard driver (step 6). You can also uninstall the latest update in Settings › Windows Update › Update history.

What are Filter Keys and Sticky Keys?

Accessibility features that change how keys respond. They're helpful for some people but can make a keyboard seem broken if turned on by accident.
