Essential Mac Keyboard Shortcuts

A handful of shortcuts saves you hundreds of trips to the menu bar every day. Learn the ones Mac users rely on most, then drill them in the trainer at the end.

01

Meet the modifier keys

A shortcut means holding one or more modifier keys, then tapping a letter or another key. Menus and Apple's guides show modifiers as symbols, so it helps to know them.

⌘Command

The main shortcut key. Next to the space bar.

⇧Shift

Usually adds a twist: Undo becomes Redo.

⌥Option

Also labeled Alt. Works on whole words and hidden extras.

⌃Control

Used less. Control-click is the same as a right-click.

🌐Fn / Globe

Bottom-left on newer keyboards. Opens emoji, dictation and more.

Coming from Windows? Most shortcuts are the same letters, just with ⌘ Command instead of Ctrl. Ctrl+C on a PC is ⌘+C on a Mac.

How to press one: hold the modifier down, tap the letter, then let go of both. For ⇧⌘Z, hold Shift and Command together, tap Z.

ShortcutWhat it does
⌘ CCopy
⌘ XCut (copy, then remove)
⌘ VPaste
⌘ ZUndo
⇧ ⌘ ZRedo (undo the undo)
⌘ ASelect all
⌘ FFind on the page or in the document
⌘ S / ⌘ PSave / Print

These copy-and-paste shortcuts work on files in Finder too: ⌘ C a file, open another folder, ⌘ V.

02

Move and edit text faster

These work in almost every app that has a text box: Mail, Notes, Pages, Word, browsers.

ShortcutWhat it does
⌘ ← / ⌘ →Jump to the start / end of the line
⌘ ↑ / ⌘ ↓Jump to the start / end of the document
⌥ ← / ⌥ →Jump one word left / right
⌥ DeleteDelete the whole word to the left
Fn DeleteForward delete (deletes to the right)
⌘ B / I / UBold / italic / underline
⌥ ⇧ ⌘ VPaste and Match Style (pastes without the original fonts and colors)
Example · fix a typo three words back

Instead of reaching for the mouse: press ⌥ ← three times to hop back three words, fix the typo, then ⌘ → to jump straight back to the end of the line.

Add Shift to select. Any of the movement shortcuts selects text if you also hold ⇧. ⇧ ⌘ → selects from the cursor to the end of the line.

03

Switch apps and manage windows

ShortcutWhat it does
⌘ TabSwitch apps. Keep holding ⌘ and tap Tab to move along the row; let go to switch.
⌘ `Switch between windows of the same app (the key above Tab)
⌘ T / ⌘ NNew tab / new window
⌘ WClose the front window or tab (the app stays open)
⌘ QQuit the app completely
⌘ MMinimize the window to the Dock
⌘ HHide the app's windows
⌘ ,Open the app's settings
⌥ ⌘ EscForce Quit an app that's frozen
⌃ ⌘ QLock your screen right away

W closes, Q quits. W and Q sit right next to each other. ⌘ Q closes every window of the app at once, so slow down near that corner of the keyboard.

Stepping away from your desk? ⌃ ⌘ Q locks the Mac so nobody can read your screen. You'll need your password or Touch ID to get back in.

04

Take screenshots

ShortcutWhat it captures
⇧ ⌘ 3The whole screen
⇧ ⌘ 4An area you drag to select (Esc cancels)
⇧ ⌘ 4 then SpaceOne window or menu: the pointer becomes a camera, click the window
⇧ ⌘ 5The Screenshot toolbar: screen recording, a timer, and where to save

Screenshots save to your Desktop unless you change it in the ⇧ ⌘ 5 Options menu.

Paste it instead of saving it. Add ⌃ Control to any screenshot shortcut, like ⌃ ⇧ ⌘ 4, to copy the picture to the clipboard. Then ⌘ V it into an email or message.

More on screenshots, including Windows and phones, in how to take a screenshot.

05

Finder and Spotlight

Spotlight is the fastest way to open anything. Press ⌘ Space, type the first few letters of an app, file or setting, and press Return. It can do quick math and conversions too: try typing 250*1.08.

In FinderWhat it does
SpaceQuick Look: preview the selected file without opening it
⌘ DeleteMove the selected file to the Trash
⇧ ⌘ NNew folder
⌘ DDuplicate the selected file
⌘ IGet Info: size, date, where it lives
⇧ ⌘ DOpen the Desktop folder
⌘ ↑Go up to the folder that contains this one

Handy Fn (🌐) shortcuts: Fn E opens emoji and symbols, Fn N opens Notification Center, and Fn C opens Control Center. On macOS Tahoe 26 or later, Fn ⇧ A shows all your Apps.

Find any shortcut yourself. Open a menu in the menu bar: the shortcut is printed on the right of each item. And in any app, ⇧ ⌘ ? opens the Help menu search, so you can type a command's name.

FAQCommon questions

Where is the Command key?

On both sides of the space bar, marked ⌘ and “command.” On some older keyboards it also shows an Apple logo.

How do I right-click on a Mac?

Hold ⌃ Control and click. On a trackpad you can also click with two fingers.

Can I use a Windows keyboard with a Mac?

Yes. The Windows key acts as ⌘ Command and Alt acts as ⌥ Option. You can swap them in System Settings › Keyboard › Keyboard Shortcuts › Modifier Keys.

My app is frozen. What do I press?

⌥ ⌘ Esc opens Force Quit. Pick the app and click Force Quit. Anything unsaved in that app will be lost.

Can I make my own shortcuts?

Yes. In System Settings › Keyboard › Keyboard Shortcuts › App Shortcuts, click +, choose an app, type the exact menu command name, and press the keys you want.
